# Design System

The code foundation follows the same three-level architecture as the design source:

Foundation -> Semantic -> Components

Components must use Semantic tokens only. Semantic tokens may reference Foundation tokens. Foundation tokens do not reference Semantic or Components.

## Foundation

Foundation tokens live in `src/design-system/tokens/primitives.css` and `src/design-system/tokens/semantic.css`, matching the source token files `primitives.tokens.json`, `semantic/*.tokens.json`, `typography.tokens.json`, and `local.color.tokens.json`.

`primitives.tokens.json` and `semantic/*.tokens.json` are intended for Figma exports and should keep Figma IDs. `typography.tokens.json` stores semantic typography roles and local typography primitives that cannot be configured or exported reliably from Figma. `local.color.tokens.json` stores local color tokens and aliases. Local token files do not include Figma IDs.

- Color
- Typography
- Space
- Radius
- Elevation
- Layout

Elevation is reserved as a foundation category, but no elevation source token exists in the current token JSON yet.

## Layout Modes

Layout modes are defined as Foundation values and applied through Semantic tokens:

- `narrow`: 320-640px
- `medium`: 641-1279px
- `wide`: 1280px and up

Components should not use breakpoints directly. If breakpoints change later, Semantic tokens absorb that change.

## Semantic

Implemented Semantic tokens include color, spacing, and typography.

Semantic typography roles expose responsive `font-size` values through the same CSS custom property for each role, for example:

- `--semantic-type-heading-lg-font-size`
- `--semantic-type-description-normal-font-size`
- `--semantic-type-button-font-size`

The CSS token implementation resolves those values by layout mode, so components continue to use semantic roles without setting breakpoint-specific font sizes locally.

State tokens are not present in the current semantic token export yet. Storybook keeps a dedicated States page so the category has a documented place when those tokens are added.
