# Grid – Layout Pattern 

## Назначение
Grid — layout-паттерн для размещения набора повторяющихся независимых элементов в адаптивной сетке. 

## Зона ответственности
Расположение и порядок элементов, количество колонок для каждого адаптивного режима, расстояния между элементами, правила перестройки по брейкпоинтам, а также поведение высоты. Вне зоны ответственности содержимое элементов, их внутренний лейаут, типографика, отступы, цвета и поведение компонентов внутри ячеек. 

## Параметры
Фиксированные значения не закладываются в паттерн. 
Используется spacing-20 для горизонтальных и вертикальных отступов. 
Конкретные токены и исключения описываются в конфигурациях паттерна. 

## Поведение по адаптивным режимам
На Wide используется четыре колонки, элементы выравниваются по высоте по самому высокому элементу, меньшие растягиваются, отступы spacing-20. 
На Medium используется две колонки, элементы переносятся на новую строку при необходимости, отступы spacing-20, высота элементов выравнивается только внутри своей строки. 
На narrow используется одна колонка, вертикальный поток, отступы spacing-20, высота каждого элемента определяется только его содержимым, выравнивания по высоте нет. 

## Примечания по использованию
Паттерн описывает только взаимное расположение и правила адаптации. 
Он не ограничивает тип контента и может использоваться с любыми повторяющимися элементами. Если появляются другие сетки, они описываются отдельными конфигурациями, ссылающимися на те же принципы поведения.
