# Responsive Modes

Этот документ определяет единые responsive modes, используемые в дизайн-системе.

Все layout-паттерны и компоненты используют эти определения и не задают собственные breakpoint-значения.

## Narrow

320–640px

## Medium

641–1279px

## Wide

≥ 1280px

## Правила использования

Названия `Narrow`, `Medium` и `Wide` во всей документации дизайн-системы относятся к responsive modes, определённым в этом документе.

Layout-паттерны и компоненты описывают своё поведение для соответствующих modes, но не переопределяют их диапазоны.

Если границы responsive modes изменяются, они изменяются только в этом документе.
