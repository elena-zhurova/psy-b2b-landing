# EqualColumns

> SideBySide Configuration

## Назначение

`EqualColumns` — конфигурация `SideBySide` для размещения двух равнозначных регионов одинаковой ширины.

Конфигурация используется в композициях, где оба региона имеют одинаковый визуальный вес и занимают равные части доступного пространства.

---

## Параметры

### Regions

На **Wide** оба региона имеют одинаковую ширину.

```text
1fr / 1fr
```

### Gap

Расстояние между регионами определяется через spacing primitives.

```text
Wide
→ primitives/spacing/80

Medium
→ primitives/spacing/40

Narrow
→ primitives/spacing/40
```

---

## Поведение

### Wide

#### Композиция

Регионы располагаются рядом.

Оба региона занимают равные части доступного пространства.

```text
width
→ 1fr / 1fr
```

#### Высота

Высота обоих регионов определяется самым высоким регионом.

Если высота регионов различается, регион с меньшей высотой растягивается до высоты более высокого региона.

```text
height
→ match tallest region
```

---

### Medium

#### Композиция

Регионы располагаются вертикально.

Второй регион располагается под первым.

Порядок регионов сохраняется.

Используется вертикальный `gap`.

#### Высота

Каждый регион имеет собственную высоту, определяемую только его содержимым.

```text
height
→ hug content
```

---

### Narrow

#### Композиция

Регионы располагаются вертикально.

Второй регион располагается под первым.

Порядок регионов сохраняется.

Используется вертикальный `gap`.

#### Высота

Каждый регион имеет собственную высоту, определяемую только его содержимым.

```text
height
→ hug content
```

---

## Примечания по использованию

`EqualColumns` используется, когда два региона должны восприниматься как равнозначные части композиции.

Правило `match tallest region` применяется только в режиме **Wide**.

В режимах **Medium** и **Narrow** высота каждого региона определяется только его собственным содержимым.

Конфигурация управляет отношением регионов друг к другу и не определяет внутренний layout или поведение компонентов, размещённых внутри регионов.
