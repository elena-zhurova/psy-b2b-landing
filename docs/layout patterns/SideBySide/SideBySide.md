# SideBySide

> Layout Pattern

## Назначение

`SideBySide` — layout-паттерн для размещения двух логических регионов.

Паттерн определяет базовую структуру композиции из двух регионов. Конкретное расположение регионов, их размеры, выравнивание и responsive-поведение определяются выбранной конфигурацией `SideBySide`.

Паттерн не определяет содержимое или визуальное оформление регионов.

---

## Зона ответственности

`SideBySide` отвечает за:

- наличие двух логических регионов;
- сохранение порядка регионов;
- применение выбранной конфигурации расположения регионов.

---

## Вне зоны ответственности

`SideBySide` не отвечает за:

- содержимое регионов;
- внутренний layout регионов;
- внутренние отступы;
- типографику;
- цвета;
- стили компонентов;
- поведение компонентов внутри регионов.

Каждый регион самостоятельно управляет своим внутренним содержимым.

---

## Параметры

### Regions

Паттерн всегда содержит два логических региона.

### Configuration

Конкретные правила расположения регионов определяются выбранной конфигурацией.

Конфигурация может определять:

- направление расположения регионов;
- соотношение ширины регионов;
- `gap` между регионами;
- выравнивание регионов;
- правила определения высоты регионов;
- изменение этих параметров между responsive modes.

---

## Поведение

`SideBySide` всегда содержит два логических региона.

Порядок регионов сохраняется независимо от выбранной конфигурации и responsive mode.

Направление композиции, соотношение размеров регионов, расстояние между ними, выравнивание и правила определения высоты задаются выбранной конфигурацией.

---

## Примечания

Внутреннее расположение элементов внутри региона определяется компонентом, который используется в качестве этого региона, и не входит в ответственность `SideBySide`.

Размеры и внутреннее поведение компонентов внутри регионов не определяются `SideBySide` или его конфигурацией, если эти параметры принадлежат самим компонентам.
