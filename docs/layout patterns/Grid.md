# Grid

> Layout Pattern

## Назначение

`Grid` — layout-паттерн для размещения набора повторяющихся независимых элементов в адаптивной сетке.

Паттерн определяет структуру сетки, количество колонок, расстояния между элементами, правила адаптивной перестройки и правила выравнивания высоты элементов.

## Зона ответственности

`Grid` отвечает за:

- количество колонок;
- расположение элементов в сетке;
- порядок заполнения сетки;
- горизонтальные и вертикальные расстояния между элементами;
- адаптивную перестройку сетки;
- правила определения высоты элементов.

## Вне зоны ответственности

`Grid` не отвечает за:

- содержимое элементов;
- внутренний layout элементов;
- внутренние отступы;
- типографику;
- цвета;
- оформление элементов;
- поведение компонентов внутри элементов.

Каждый элемент самостоятельно управляет своим содержимым и внутренней структурой.

## Параметры

### Responsive Modes

| Mode | Колонки |
|------|---------:|
| Wide | 4 |
| Medium | 2 |
| Narrow | 1 |

### Gap

Расстояние между колонками и элементами определяется через spacing primitives.

```text
Horizontal Gap
→ primitives/spacing/20

Vertical Gap
→ primitives/spacing/20
```
---

## Поведение

### Wide

- используется сетка из четырёх колонок;
- элементы располагаются слева направо, сверху вниз;
- горизонтальный и вертикальный `gap` — `spacing-20`;
- высота всех элементов определяется самым высоким элементом сетки;
- элементы с меньшей высотой растягиваются до высоты самого высокого элемента.

### Medium

- используется сетка из двух колонок;
- элементы автоматически переносятся на следующую строку;
- горизонтальный и вертикальный `gap` — `spacing-20`;
- высота элементов выравнивается только внутри своей строки;
- элементы с меньшей высотой растягиваются до высоты самого высокого элемента своей строки.

### Narrow

- используется одна колонка;
- элементы располагаются вертикальным потоком;
- горизонтальный и вертикальный `gap` — `spacing-20`;
- высота каждого элемента определяется только его собственным содержимым;
- выравнивание высоты не применяется.

## Примечания по использованию

`Grid` предназначен для размещения повторяющихся независимых элементов.

Паттерн не предполагает конкретный тип содержимого. В сетке могут размещаться карточки, преимущества, тарифы, изображения, профили, статистика и любые другие повторяющиеся компоненты.

Паттерн описывает только структуру размещения элементов и их адаптивное поведение. Все решения, связанные с содержимым и внутренним устройством элементов, принимаются самими компонентами.
